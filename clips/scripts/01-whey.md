# คลิป 01: เวย์โปรตีนจากจีน 1 ตัน เสียภาษี 0 บาท?!

ความยาว: ~35 วินาที | ที่มา: `_whey_ans2.txt`

## สคริปต์ (พูด + ตัวอักษรบนจอ)

**0–3 วิ HOOK** (หน้าคนพูด + ตัวอักษรใหญ่เต็มจอ)
- พูด: "นำเข้าเวย์ 1 ตัน เสียภาษีเท่าไหร่? คำตอบอาจทำให้คุณตกใจ"
- บนจอ: `เวย์ 1 ตัน = ภาษี 0 บาท?!`

**3–10 วิ ตั้งคำถาม** (อัดจอตอนพิมพ์คำถามในเว็บ)
- พิมพ์: "นำเข้าเวย์โปรตีน isolate 70% จากจีน 1,000 กก. CIF 670,000 บาท ขอพิกัด อากร Form E ใบอนุญาต"
- พูด: "ลองถาม AI พิกัดศุลกากรดู"

**10–28 วิ เฉลย** (อัดจอเลื่อนคำตอบ + ซูมตัวเลขทีละจุด)
- พูด: "พิกัด 3504.10.10 อากรปกติ 10% เป็นเงิน 67,000 บาท — แต่ถ้ามี Form E จากจีน เหลือ 0 บาท ประหยัดไป 67,000 เต็มๆ"
- บนจอไฮไลต์: `3504.10.10` → `67,000` → `Form E = 0 บาท`
- พูดต่อ: "แต่ระวัง เวย์เป็นอาหาร ต้องมี อย. ก่อนนำเข้า ไม่งั้นของติดด่าน"
- บนจอ: `⚠️ ต้องมี อย. ก่อนนำเข้า`

**28–35 วิ CTA** (หน้าคนพูด)
- พูด: "อยากรู้พิกัดสินค้าของคุณ คอมเมนต์ชื่อสินค้าไว้ หรือทัก LINE OA ได้เลย กดติดตาม มีพิกัดใหม่ทุกวัน"
- บนจอ: `LINE OA: lin.ee/Z55Jn7C` + ปุ่ม Follow

## ช็อตลิสต์วันอัด

1. A-roll hook (หน้าตรง) × 3 เทค
2. อัดจอ: พิมพ์คำถาม → กดส่ง → รอคำตอบ (เผื่อเวลาจริง AI ตอบช้า ตัดเร่งได้)
3. อัดจอ: เลื่อนคำตอบช้าๆ ซูมเลข 3504.10.10 / 67,000 / 0 บาท / อย.
4. A-roll CTA × 2 เทค
