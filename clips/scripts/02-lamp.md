# คลิป 02: ของ 7 อย่างจากจีน พิกัดเดียวกันหมด? ผิด!

ความยาว: ~40 วินาที | ที่มา: `_lamp_ans.txt`

## สคริปต์ (พูด + ตัวอักษรบนจอ)

**0–3 วิ HOOK** (หน้าคนพูด + ตัวอักษรใหญ่เต็มจอ)
- พูด: "ของ 7 อย่าง สั่งจากจีนพร้อมกัน พิกัดเดียวกันหมด? ผิดครับ"
- บนจอ: `7 ชิ้นส่วน = 3 พิกัด?!`

**3–12 วิ ตั้งคำถาม** (อัดจอตอนพิมพ์คำถามในเว็บ)
- พิมพ์: "นำเข้าชิ้นส่วนขั้วหลอดไฟ E26 จากจีน 7 รายการ ใช้ผลิตสายไฟประดับ ขอพิกัด AHTN อากร Form E ใบอนุญาต ตอบเป็นตาราง"
- พูด: "ลองถามทีเดียว 7 รายการดู"

**12–32 วิ เฉลย** (อัดจอเลื่อนตารางคำตอบ + ซูมแถวที่ต่าง)
- พูด: "ส่วนใหญ่ลง 9405.99.90 อากร 10% Form E เหลือ 0 — แต่มีตัวแสบ 3 ตัว: ตัวเรือนพลาสติกไป 9405.92.00, ขั้วต่อไฟฟ้าไป 8536.90.99, และสปริงตัวเดียวโดดไป 7320.20.90 เพราะสปริงมีพิกัดของตัวเอง"
- บนจอไฮไลต์ทีละแถว: `9405.92.00` → `8536.90.99` → `🔥 สปริง 7320.20.90`
- พูดต่อ: "จำพิกัดผิดตัวเดียว เสียหายหลักหมื่น แถมของติดด่าน"
- บนจอ: `⚠️ จำพิกัดผิด = ของติดด่าน`

**32–40 วิ CTA** (หน้าคนพูด)
- พูด: "มีของหลายรายการแบบนี้ ส่งลิสต์มาถามได้เลย ทัก LINE OA หรือคอมเมนต์ไว้ กดติดตาม มีพิกัดใหม่ทุกวัน"
- บนจอ: `LINE OA: lin.ee/Z55Jn7C` + ปุ่ม Follow

## ช็อตลิสต์วันอัด

1. A-roll hook (หน้าตรง) × 3 เทค
2. อัดจอ: พิมพ์คำถาม → กดส่ง → รอคำตอบ (ตารางยาว เผื่อเวลาโหลด)
3. อัดจอ: เลื่อนตารางช้าๆ หยุดซูม 3 แถวที่พิกัดต่าง
4. A-roll CTA × 2 เทค
