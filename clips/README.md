# โปรเจกต์คลิปสั้น thai-customs

เป้าหมาย: คลิปละ 30–45 วินาที แนวตั้ง (9:16) ลง TikTok / Reels / Shorts วันละ 1 คลิป
คอนเซปต์: "ถามพิกัดสินค้าจริง ได้คำตอบพร้อมตัวเลขอากรในไม่กี่วินาที"

## โครงโฟลเดอร์

```
clips/
├── README.md              # ไฟล์นี้
├── content-plan.md        # แผนคอนเทนต์ + สถานะแต่ละคลิป
├── recording-checklist.md # เช็กลิสต์วันอัด (พรุ่งนี้)
├── editing-workflow.md    # ขั้นตอนตัดต่อด้วยกัน
├── scripts/               # สคริปต์ทีละคลิป (01, 02, ...)
├── raw/                   # ฟุตเทจดิบ (ไม่ commit ไฟล์วิดีโอ)
├── edited/                # ไฟล์ตัดเสร็จรอลง
└── published/             # ไฟล์ที่ลงแล้ว + โน้ตผลตอบรับ
```

## เวิร์กโฟลว์

1. เลือกหัวข้อจาก `content-plan.md` → เขียน/ทบทวนสคริปต์ใน `scripts/`
2. วันอัด: ทำตาม `recording-checklist.md` → เก็บไฟล์ดิบลง `raw/`
3. ตัดต่อด้วยกันตาม `editing-workflow.md` → ไฟล์เสร็จลง `edited/`
4. ลงทุกแพลตฟอร์ม → ย้ายไฟล์ลง `published/` + อัปเดตสถานะใน `content-plan.md`

## กติกา

- ตั้งชื่อไฟล์: `YYYYMMDD_<หัวข้อ>_<ส่วน>_t<เทค>.mp4` เช่น `20261009_whey_hook_t1.mp4`
- ห้าม commit ไฟล์วิดีโอ/เสียง (ดู `.gitignore`) — เก็บแค่สคริปต์กับโน้ตใน git
- ก่อนลงทุกคลิป เช็ก privacy: เบลออีเมล/uid/ยอดเครดิตบนจอให้หมด
- ทุกคลิปต้องมี CTA เดียวกัน: กดติดตาม + LINE OA (https://lin.ee/Z55Jn7C)
