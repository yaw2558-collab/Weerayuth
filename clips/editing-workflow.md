# ขั้นตอนตัดต่อด้วยกัน

เครื่องมือแนะนำ: **CapCut** (ฟรี มี auto-caption ภาษาไทย) — ถนัดตัวอื่นก็ใช้ได้ ขั้นตอนเหมือนกัน

## แบ่งงาน

- คุณ: กดโปรแกรม ตัด ใส่เอฟเฟกต์ ส่งไฟล์/แคปหน้าจอมาให้ดู
- ผม: ช่วยเลือกเทค (จากโน้ตเทคที่ดีสุด) เขียนข้อความบนจอ แคปชัน แฮชแท็ก เช็ก pacing + เช็กลิสต์ก่อนลง

## ขั้นตอนต่อ 1 คลิป

1. **Import + selects** — เอาฟุตเทจจาก `clips/raw/` ลงไทม์ไลน์ เลือกเทคดีสุดของ hook / demo / CTA
2. **Rough cut** — เรียง hook → พิมพ์คำถาม (เร่งสปีด 1.5–2×) → เฉลยตัวเลข → CTA ตัดช่องว่าง/คำอุทานออกให้หมด
3. **ซับไตเติล** — auto-caption ภาษาไทย แล้วแก้คำผิด (โดยเฉพาะตัวเลขพิกัด!) ฟอนต์ใหญ่ อ่านออกบนมือถือ
4. **ข้อความ hook** — ใส่ตัวอักษรใหญ่ตั้งแต่วินาทีแรก (ดูสคริปต์: `เวย์ 1 ตัน = ภาษี 0 บาท?!` / `7 ชิ้นส่วน = 3 พิกัด?!`)
5. **ไฮไลต์ตัวเลข** — ซูม/วงกลมเลขพิกัดกับตัวเลขเงินตอนพูดถึง (คนหยุดดูเพราะเลข)
6. **แบรนดิ้ง** — ใส่ลายน้ำโลโก้มุมจอ + การ์ดท้าย CTA มี LINE OA (`lin.ee/Z55Jn7C`)
7. **เสียง** — เพลงประกอบเบาๆ (ต่ำกว่าเสียงพูดเยอะ) ตัดเสียงรบกวน
8. **Export** — 1080×1920 H.264 ลง `clips/edited/` ชื่อ `YYYYMMDD_<หัวข้อ>_final.mp4`

## เช็กลิสต์ก่อนลง (ทุกคลิป)

- [ ] hook จบใน 3 วิ + มีตัวอักษรใหญ่ตั้งแต่เฟรมแรก
- [ ] ความยาวรวมไม่เกิน 45 วิ
- [ ] ตัวเลขพิกัด/เงินถูกต้องตรงกับคำตอบจริง
- [ ] เบลออีเมล / uid / ยอดเครดิตบนจอแล้ว
- [ ] มี CTA + LINE OA ท้ายคลิป
- [ ] มี disclaimer ในคลิปหรือแคปชัน: "ข้อมูลเบื้องต้น ไม่ใช่คำวินิจฉัยของกรมศุลกากร"
- [ ] ดูรอบสุดท้ายบนมือถือจริง 1 รอบ (ภาพ/เสียง/ซับ)
